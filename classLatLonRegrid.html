Detailed Description

Bilinear interpolation of a 2D field from a rectilinear lat-lon grid onto REMORA's rho points, the way ROMS's regrid does for forcing.

The source grid is given by 1D longitude and latitude axes, each strictly monotone in either direction; the longitude may be in [-180, 180) or [0, 360), may cross the branch cut, and may cover the globe, in which case it is treated as periodic. The target points are the model's lon_rho and lat_rho on level 0 over the domain and its one-cell ring, the cells a file on the model grid fills.

The interpolation weights are computed once, in define(), and stored per target cell in the layout the coupling remap uses: up to four weights, and the (i, j, k) source index of each. They depend only on the source axes and the target points, not on the variable, so every field on the same source grid and forcing layout shares one copy: define() hands out the weights an earlier field built, when there is one still in use. It also finds the box of source cells this rank's stencils and nearest-valid search can reach (across the seam of a periodic longitude, when that is shorter), and apply() reads only that box of each record, every rank at once in a collective read. apply() sets aside source values equal to the variable's _FillValue or missing_value (or not finite), unpacks the rest with its scale_factor and add_offset, renormalizes the remaining weights, and gives a target point whose four corners are all missing the nearest valid source value within LatLonRegridOptions::fill_max_rings cells.
