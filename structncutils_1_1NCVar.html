void ncutils::NCVar::put_varn_all ( int num,
MPI_Offset *const * starts,
MPI_Offset *const * counts,
const double * dptr ) const

Write out num subarrays in a single collective call. Every rank that opened the file must call this, in the same order, but num may differ between ranks and may be zero. starts[i]/counts[i] describe subarray i, and dptr holds all subarrays' data concatenated in that order.
