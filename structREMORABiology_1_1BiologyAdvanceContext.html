Detailed Description

Host views at the existing biology source-update stage.

old_state holds concentrations. new_state receives additive Hz-weighted increments; it must not be overwritten with scratch concentrations. Optional forcing views default to null and are validated by the concrete model. Fill it with designated initializers so the pointers cannot be transposed silently. This is a host context: device kernels capture plain views/parameters, not this object.
