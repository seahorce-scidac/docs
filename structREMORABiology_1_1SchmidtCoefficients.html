Detailed Description

Air-sea O2 and CO2 exchange shared by the Fennel and ECB kernels, whose ROMS sources (fennel.h, ecb.h) carry identical copies of these formulas.

Each coefficient set belongs to one published relation, so the Schmidt polynomial and the leading rate coefficient of the transfer velocity are selected together; ROMS makes the same pairings with RW14_OXYGEN_SC, OCMIP_OXYGEN_SC and RW14_CO2_SC. Pick a set on the host and capture it by value: the kernels never read these namespace-scope objects on the device.
