void REMORAPC::WritePlotFile ( const std::string &  a_fname,
const std::string &  a_name,
const amrex::Vector< amrex::MultiFab > &  a_xy 
) const

Write the particles to a plotfile with x and y in physical coordinates

Write the particles to a plotfile with x and y in physical coordinates. The particles move in the uniform coordinates of the AMReX geometry; for output, x and y are replaced by the physical coordinates of the cell corners (psi points) interpolated bilinearly to each particle. These are the corner positions the plotfile's nodal displacement gives a viewer, so each particle is drawn inside the cell that holds it. z is already the physical height. Only a copy of the particles is converted, so writing a plotfile does not change the run.

Parameters
a_fnameplotfile directory
a_nameparticle species name
a_xyper level, physical x and y of the psi points (REMORA::plot_node_coords)
