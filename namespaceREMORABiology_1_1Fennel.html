Map the Fennel tracers onto cons components starting at base.

base is REMORA::bio_comp_start(), which is Tracer_comp plus the number of passive (dye) scalars. Passing it explicitly keeps biology working when a run carries dye as well, since the biology block then does not start at Tracer_comp.
