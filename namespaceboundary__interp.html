AMREX_GPU_HOST_DEVICE AMREX_FORCE_INLINE void boundary_interp::cell_centered_weight ( int f,
int r,
int & c,
amrex::Real & w )

For fine cell f along a cell-centered strip refined by r, find the coarse cell c below it and the weight w of coarse cell c+1, so that the fine value is crse[c] + w*(crse[c+1] - crse[c]). Fine cell f is centered at (f+0.5)/r coarse cell widths and coarse cell c at c+0.5. When w is zero, crse[c+1] need not exist.

Parameters
[in]ffine cell index
[in]rrefinement ratio along the strip
[out]clower coarse cell index
[out]wweight of coarse cell c+1, in [0, 1)

For fine node f along a nodal strip refined by r, find the coarse node c at or below it and the weight w of coarse node c+1, as for cell_centered_weight. Fine node f lies at f/r coarse cell widths and coarse node c at c, so w is zero where the nodes coincide.

Parameters
[in]ffine node index
[in]rrefinement ratio along the strip
[out]clower coarse node index
[out]wweight of coarse node c+1, in [0, 1)
