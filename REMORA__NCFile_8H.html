Helper function for testing whether a file carries every named variable.

Call this before reading optional variables: ReadNetCDFFile() dereferences ncf.var(name) unconditionally, so a missing name is a hard failure.

Parameters
fnameName of NetCDF file
var_namesNames of the variables to test for
Returns
whether every named variable is present in the file

Use this before calling BuildFABsFromNetCDFFile() on optional variables: ReadNetCDFFile() calls ncf.var(name) unconditionally, so a missing variable is a hard failure rather than a recoverable one. The answer is broadcast so every rank agrees before any collective read is attempted.

◆ ReadNetCDFTimeOffsetDays()

double ReadNetCDFTimeOffsetDays ( const std::string & fname,
const std::string & time_name,
double time_ref,
bool units_required,
bool announce )

Offset, in days, that puts a file's time variable onto the model clock.

Reads the units attribute of time_name, which must count days, and its calendar attribute if it has one. A days since <date> reference date is converted to days since the date remora.time_ref names, so a file whose epoch differs from the run's is still read at the right time; the offset is zero when the two dates agree. A time variable with no reference date is taken to be on the model clock already. A calendar that disagrees with time_ref is an error, since the two would count days differently.

Collective: the attributes are read on the I/O processor and the result is broadcast. The mapping applied is printed, so a reader of the log can see it.

Parameters
[in]fnameNetCDF file
[in]time_namename of the time variable
[in]time_refremora.time_ref
[in]units_requiredabort when the time variable has no units attribute; otherwise warn and assume days on the model clock
[in]announceprint the mapping; false for a series that is set up but will never be read
