inline

The number of points, over all ranks, at which a and b differ in bit pattern in any of the components [0, ncomp), over each box grown by ng; with a mask, only where it equals mask_val. a, b and the mask share a layout. The comparison makes no floating-point operation, so the signalling NaNs of cells never written compare equal to themselves without trapping.

Parameters
[in]afirst data
[in]bsecond data
[in]ncompnumber of components compared, from 0
[in]ngghost cells compared
[in]maskwhere to compare, or nullptr for everywhere
[in]mask_valthe mask value that selects a point
