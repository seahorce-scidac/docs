◆ open_local()

NCFile ncutils::NCFile::open_local ( const std::string & name)
inlinestatic

Open an existing file read-only on the calling rank alone, for a reader that reads on one rank and broadcasts what it found.

The file stays in collective data mode, so read it with the get_all() calls, which are collective over this one rank. Independent mode is not an option for NetCDF-4: netCDF-C refuses independent access to a compressed variable, and HDF5 reads metadata collectively over the ranks that opened the file.
