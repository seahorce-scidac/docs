Detailed Description

An amrex::AMRErrorTag that does not let the coastline drive refinement.

AMReX writes each data-dependent test twice: a plain form, and an embedded-boundary form that skips a covered cell and differences only across a face EBCellFlag reports as open. REMORA's land/sea mask plays the part of that connectivity – tracers on the land side are zeroed every step, so a difference taken across a coast measures the coast, not the flow. This class is that EB form with mskr in place of the flags.

A box region (in_box_lo/in_box_hi) is guarded too: it tags only the water cells inside it, unless SetTagLand asks for the whole rectangle.

Guarding each criterion as it is evaluated, rather than clearing land-adjacent tags afterwards, leaves every other criterion's tags alone.

The inheritance is private on purpose: AMRErrorTag::operator() is not virtual, so converting a criterion back to the base would compile and quietly run the unguarded test on masked data. Private inheritance makes that ill-formed while still granting access to the protected m_test, m_value and m_info. Only the constructors and Field() are re-exported; the base's seven-argument operator() deliberately is not, so a call that forgets the mask will not compile.

Apply this criterion to tba, skipping land.

GRAD, LESS, GREATER and BOX consult the mask. PARSER tags on position alone, USER hands the whole decision to a functor, and VORT and RELGRAD are unreachable from REMORA's inputs; all of those go to amrex::AMRErrorTag::operator() unchanged.

Parameters
[in,out]tbatags to update
[in]mfsingle-component field this criterion tests, with one ghost cell when the test is GRAD
[in]mskr3dland/sea mask on mf's BoxArray and DistributionMap, with enough lateral ghost cells for mask_lo/mask_hi plus one more for GRAD. nullptr evaluates exactly as amrex::AMRErrorTag would, which is what a criterion keyed on the mask itself wants, and what a run with no mask wants since every value is then clean anyway.
[in]clearvalvalue marking an untagged cell
[in]tagvalvalue marking a tagged cell
[in]timecurrent time
[in]levellevel being tagged
[in]geomgeometry of that level
[in]mask_lolowest offset, in rho-cells relative to a value's own index, of the cells whose wet/dry state that value depends on – not always the cell it is stored in, since a face velocity is masked by both cells sharing its face and vorticity by a 3x3 block. Testing a value where it is not clean tags the coast just as differencing across the coast would. ErrorEst sets these per field and says why. Zero, the default, means the value is its own cell alone; the vertical component must be zero, the mask being column-constant.
[in]mask_hihighest such offset; see mask_lo.

Apply this criterion to tba, skipping values the land/sea mask makes meaningless. The parameters are documented on the declaration in REMORA_ErrorTag.H.

The one thing to know when reading the body: a cell this declines to test is left exactly as it was found, not cleared. That is what keeps one criterion's tags from being undone by another, and it is the whole difference from the derefine criteria this replaced.
