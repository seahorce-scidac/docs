Detailed Description

Components of the per-level metric products (vec_metric_r/u/v/p), computed once from pm and pn in set_derived_metrics so the time step multiplies instead of dividing. Names follow ROMS metrics.F; each is evaluated with exactly the expression the kernels used before, so reading the stored value is bitwise identical to recomputing it.
