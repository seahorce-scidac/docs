helper function checking that a high-resolution file covers the refined domain plus grow cells

Parameters
fnamefile name the hires data will be read from
var_namea rho-point variable in that file whose horizontal extent is checked
domainthe refined full-domain box the data has to cover
ngrowgrow cells the read asks for, i.e. cum_ref_ratios[hires_*_level]

A high-resolution file has to carry the refined domain plus ngrow rings on every side (Docs/sphinx_doc/Inputs.rst). Checking that up front is not a nicety: BuildFABsFromNetCDFFile copies on intersection and fill_fab_from_arrays only asserts that the destination box is big enough for the source, so a file with too FEW grow cells reads cleanly and silently leaves the outer rings of the FAB at whatever they held – which then gets averaged down into level 0. Only rho-point variables are checked; that is enough to catch an undersized file, and it avoids re-deriving the staggered offsets here.

helper function to read grid variables a file may or may not carry (spherical coordinates, rotation angle) from netcdf; returns whether it did

Parameters
domainsimulation domain
fnamefile name to read from
namesvariables to read, each 2D on (eta, xi) with no time axis
fabsone container per name
whatwhat the variables are, for the log line
ngrowgrow cells the file carries, if not the usual one-cell ring
Returns
whether the file carried every variable and they were read

ROMS grid files carry some variables only for some grids: lon_psi/lat_psi and lon_rho/lat_rho for a spherical grid (the corner arrays a coupled driver remaps with, as SCRIP/COAWST does in Lib/SCRIP_COAWST/read_roms.f, and the cell centers a forcing field on another grid is interpolated to), and angle, the angle in radians from east to the local xi axis, positive counterclockwise, that rotates an east/north wind onto the grid axes. Idealized grid files carry none of them, so these reads are optional and report whether they happened rather than aborting. The variables of one call stand or fall together: a partial set is reported as absent.
