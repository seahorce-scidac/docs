void REMORAFillPatcher::FillSetKept ( amrex::MultiFab & mf,
amrex::Real time,
amrex::Vector< amrex::BCRec > const & bcs,
bool check )

FillSet without a coarse boundary condition, keeping the values it writes so that the next call for the same time and registered data replays them; with check, a replay also interpolates and aborts if the two differ.

FillSet with no coarse boundary condition (as every REMORA caller passes), for fills that repeat at one time: the barotropic fills of a fine level, which all ask for the start of the fine step. The values written into the set region are kept, and a later call with the same registered data, time and layout writes them again instead of interpolating. That gives the same values only when they depend on the coarse data alone (SetValuesFromCoarseOnly); otherwise every call interpolates. With check, a replay also interpolates into a copy of mf and aborts if any set value differs in bit pattern from the kept one.

Parameters
[in,out]mffine data
[in]timetime to fill at
[in]bcsboundary condition types, for the cell interpolater
[in]checkwhether a replay is checked against a fresh interpolation

◆ SetValuesFromCoarseOnly()

bool REMORAFillPatcher::SetValuesFromCoarseOnly ( )

Whether the set region's values depend on the registered coarse data alone.

Whether what Fill writes into the set region is a function of the registered coarse data and the time alone. Cell data and the faces interpolated along the face (the faces on coarse faces) are. A face between two coarse faces is interpolated from the fine faces on either side, which are not set unless they too are in the region, so such a face makes the result depend on the fine data as well.
