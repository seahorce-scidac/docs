Detailed Description

ECB ecosystem with the fixed ROMS option set CARBON, OXYGEN, BIO_SEDIMENT, DENITRIFICATION, PO4, TALK_NONCONSERV, RW14_OXYGEN_SC and RW14_CO2_SC. Polymorphism is host-only; kernels capture plain data.
