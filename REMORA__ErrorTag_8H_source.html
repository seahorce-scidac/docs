10/**
11 * An amrex::AMRErrorTag that does not let the coastline drive refinement.
12 *
13 * AMReX writes each data-dependent test twice: a plain form, and an embedded-boundary form
14 * that skips a covered cell and differences only across a face EBCellFlag reports as open.
15 * REMORA's land/sea mask plays the part of that connectivity -- tracers on the land side are
16 * zeroed every step, so a difference taken across a coast measures the coast, not the flow.
17 * This class is that EB form with mskr in place of the flags.
18 *
19 * REMORA used to suppress the same spurious tags afterwards instead, by appending two
20 * derefine criteria that cleared every land cell and every cell beside one. Running after the
21 * user's own criteria, they also cleared tags a static in_box_lo/in_box_hi region had
22 * deliberately set, so a box drawn across a coast came back refined only on its water part.
23 * Guarding each criterion as it is evaluated leaves every other criterion's tags alone.
24 *
25 * The inheritance is private on purpose: AMRErrorTag::operator() is not virtual, so converting
26 * a criterion back to the base would compile and quietly run the unguarded test on masked
27 * data. Private inheritance makes that ill-formed while still granting access to the protected
28 * m_test, m_value and m_info. Only the constructors and Field() are re-exported; the base's
29 * seven-argument operator() deliberately is not, so a call that forgets the mask will not
30 * compile.
31 */
