Detailed Description

Keeps the files BuildLocalFABsFromNetCDFFile opens open until the outermost session ends, so a run of readers opens each file once.

Opening a NetCDF-4 file in parallel costs about a second on a thousand ranks, and the initialization routines read the grid file alone half a dozen times. Create one of these, on every rank, around such a run of readers; sessions nest, and the files close, collectively and in the order they were opened, when the outermost one is destroyed. A file is kept per communicator, so a reader over another communicator gets its own handle. Only for files that are read, not written, while it lasts.
