Detailed Description

Runtime parameters of the ECB (Estuarine Carbon Biogeochemistry) model, read from remora.ecb.*. Units and defaults follow ROMS External/bio_ECB.in at the commit given in Docs/sphinx_doc/ECB.rst; the defaults are the values that file sets, not the suggestions in its comments.
